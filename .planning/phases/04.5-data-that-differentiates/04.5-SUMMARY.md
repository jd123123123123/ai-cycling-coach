## Decisions Made

- **uPlot legend off**: Native uPlot legend disabled, existing `LegendPip` bottom strip preserved — visual consistency.
- **Recharts for donut**: IntensityDistribution kept on Recharts PieChart — avoids another ECharts import for something Recharts handles fine.
- **Sparkline extension not new component**: `bandValues` prop added to existing Sparkline — cleanest path, no component split needed.
- **EF scatter dots via paths:null**: uPlot path builder returning null means no line drawn; only the `points` config renders — correct scatter behavior.
- **ECharts VisualMapComponent required**: Even with tree-shaking, CalendarComponent needs VisualMapComponent to drive color scale; both pulled in.
