  <action>
    Create `backend/app/services/garmin_client.py` with:

    1. `GarminProvider` Protocol (typing.Protocol for structural subtyping):
       ```python
       class GarminProvider(Protocol):
           async def authenticate(self) -> None: ...
           async def get_activities(self, start_date: date, end_date: date) -> list[dict]: ...
           async def get_sleep(self, for_date: date) -> dict | None: ...
           async def get_hrv(self, for_date: date) -> dict | None: ...
           async def get_body_battery(self, start_date: date, end_date: date) -> list[dict]: ...
           async def get_training_status(self, for_date: date) -> dict | None: ...
           async def get_heart_rates(self, for_date: date) -> dict | None: ...
           async def get_stress(self, for_date: date) -> dict | None: ...
           async def get_user_summary(self, for_date: date) -> dict | None: ...
       ```

    2. `GarminConnectClient` class implementing the Protocol:
       - Constructor: `__init__(self, email: str, password: str, token_store_path: str | None = None)`
       - Stores email, password, token_store_path. `_api: Garmin | None = None`
       - `async def authenticate(self)`: Creates `Garmin(email, password)` instance, calls `api.login(tokenstore=token_store_path)` via `asyncio.to_thread`. Stores result in `self._api`.
       - `async def _ensure_auth(self)`: Calls `authenticate()` if `self._api is None`.
       - ALL data methods follow this pattern:
         ```python
         async def get_activities(self, start_date: date, end_date: date) -> list[dict]:
             await self._ensure_auth()
             return await asyncio.to_thread(
                 self._api.get_activities_by_date,
                 start_date.isoformat(),
                 end_date.isoformat(),
             )
         ```
       - `get_sleep(for_date)` -> calls `self._api.get_sleep_data(for_date.isoformat())`
       - `get_hrv(for_date)` -> calls `self._api.get_hrv_data(for_date.isoformat())`
       - `get_body_battery(start_date, end_date)` -> calls `self._api.get_body_battery(start_date.isoformat(), end_date.isoformat())`
       - `get_training_status(for_date)` -> calls `self._api.get_training_status(for_date.isoformat())`
       - `get_heart_rates(for_date)` -> calls `self._api.get_heart_rates(for_date.isoformat())`
       - `get_stress(for_date)` -> calls `self._api.get_all_day_stress(for_date.isoformat())`
       - `get_user_summary(for_date)` -> calls `self._api.get_user_summary(for_date.isoformat())`
       - Each method wraps the sync library call in `asyncio.to_thread(...)`.
       - Each method has a try/except for `GarminConnectAuthenticationError` that logs the error and re-raises as a custom `GarminAuthError(Exception)`.
       - Import `from garminconnect import Garmin, GarminConnectAuthenticationError` inside the class methods (lazy import to avoid import-time dependency).

    3. Define `GarminAuthError(Exception)` at module level — raised when garmin auth fails so the sync service can handle it (disable sync, update status).

    4. Add module-level logger: `logger = logging.getLogger(__name__)`
  </action>
