<objective>
Extend AthleteProfile with target-event metadata so the periodization engine in Plan 02 has a goal anchor. Surface those fields in the profile setup UI.

Purpose: The mesocycle generator needs structured access to (a) when the athlete's A/B/C event is, (b) what kind of event it is (race/fondo/audax/maintenance), and (c) priority — so it can pick the right Friel phase progression and trigger Mujika taper logic in Phase 7.2. Today this lives buried inside `AthleteProfile.goals` JSONB; promoting it to first-class columns gives the generator a clean contract and avoids JSON-key drift across services.

Output: Migration, ORM columns, Pydantic schema fields, GET/PATCH wiring, ProfileSetupPage form additions.
</objective>
