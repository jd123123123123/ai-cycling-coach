<objective>
Build the sync service that transforms Garmin data into our domain models. This includes the activity mapper (Garmin JSON -> ActivityCreate), daily metric service (biometrics upsert with app-layer uniqueness), and the sync orchestrator that ties everything together.

Purpose: This is the core business logic that bridges Garmin's data format to our training engine. Activities synced here flow through create_activity which auto-calculates TSS, making them instantly available in PMC/CTL/ATL/TSB calculations. Daily metrics provide the biometric data that Phase 4 dashboard and Phase 5 AI coaching need.

Output: garmin_mapper.py, daily_metric_service.py, garmin_sync_service.py - the complete sync pipeline from Garmin API responses to persisted, TSS-calculated activities and biometrics.
</objective>

    1. Create `backend/app/services/garmin_mapper.py`:

       **GARMIN_SPORT_MAP dict** mapping Garmin activityType.typeKey to our sports:
       ```python
       GARMIN_SPORT_MAP = {
           "cycling": "cycling",
           "road_biking": "cycling",
           "mountain_biking": "cycling",
           "gravel_cycling": "cycling",
           "indoor_cycling": "cycling",
           "virtual_ride": "cycling",
           "running": "running",
           "trail_running": "running",
           "treadmill_running": "running",
           "strength_training": "gym",
           "fitness_equipment": "gym",
       }
       ```

       **`map_garmin_activity(raw: dict) -> ActivityCreate | None`**:
       - Extract `activityType.typeKey` via `raw.get("activityType", {}).get("typeKey", "")` and look up in GARMIN_SPORT_MAP. Return None if sport not mapped.
       - Parse `started_at` from `raw.get("startTimeGMT")` falling back to `raw.get("startTimeLocal")`. Parse with `datetime.fromisoformat(...)` and attach UTC: `.replace(tzinfo=timezone.utc)`. Handle the case where the string might already have timezone info.
       - Map fields:
         - `sport` from GARMIN_SPORT_MAP
         - `started_at` parsed above
         - `duration_seconds` = `int(raw.get("duration", 0))` or None if 0
         - `distance_meters` = `raw.get("distance")`
         - `average_hr` = `raw.get("averageHR")`
         - `max_hr` = `raw.get("maxHR")`
         - `calories` = `raw.get("calories")`
         - `title` = `raw.get("activityName")`
         - `average_power` = `raw.get("avgPower") or raw.get("averagePower")` — try both key names (LOW confidence on exact name, per research)
         - `normalized_power` = `raw.get("normalizedPower")`
         - `source` = `"garmin"` (hardcoded)
         - `external_id` = `str(raw["activityId"])` — this is required; if missing, log warning and return None
       - Return `ActivityCreate(...)` with all mapped fields.
       - Use `.get()` with None default for ALL optional fields — power fields especially may be absent.

       **`map_daily_metrics(sleep_data: dict | None, hrv_data: dict | None, body_battery_data: list[dict] | None, heart_rate_data: dict | None, stress_data: dict | None, user_summary: dict | None) -> dict`**:
       - Returns a flat dict with keys matching DailyMetric columns.
       - Sleep score: try `sleep_data.get("dailySleepDTO", {}).get("sleepScores", {}).get("overall", {}).get("value")` FIRST, then fall back to `sleep_data.get("dailySleepDTO", {}).get("sleepScore")`. Guard against None at every level.
       - HRV: `hrv_data` can be None (device doesn't support it). If not None, try `hrv_data.get("hrvSummary", {}).get("lastNight")` then fall back to `hrv_data.get("hrv5MinHigh")`.
       - Body battery: if `body_battery_data` is a non-empty list, use `body_battery_data[0].get("charged")`.
       - Resting HR: `heart_rate_data.get("restingHeartRate")` if heart_rate_data is not None.
       - Stress level: `stress_data.get("avgStressLevel")` if stress_data is not None.
       - Steps: `user_summary.get("totalSteps")` if user_summary is not None.
       - Collect all raw responses into a `raw_data` dict: `{"sleep": sleep_data, "hrv": hrv_data, "body_battery": body_battery_data, "heart_rates": heart_rate_data, "stress": stress_data, "summary": user_summary}`
       - Return dict with all fields, None for any missing data.

    2. Create `backend/app/services/daily_metric_service.py`:

       **`async def upsert_daily_metric(db: AsyncSession, user_id: int, for_date: date, data: dict) -> DailyMetric | None`**:
       - App-layer uniqueness enforcement: SELECT existing DailyMetric WHERE user_id == user_id AND date == for_date. If exists, return None (skip — do not overwrite existing data).
       - If not exists, create DailyMetric with:
         - `user_id`, `date=for_date`, `recorded_at=datetime.now(timezone.utc)` (partition column)
         - All metric fields from `data` dict: sleep_score, hrv_status, body_battery, resting_hr, stress_level, steps
         - `source="garmin"`, `raw_data=data.get("raw_data")`
       - `db.add(metric)`, `await db.flush()` (NOT commit — let caller control transaction)
       - Return the created DailyMetric.

       **`async def get_daily_metrics(db: AsyncSession, user_id: int, start_date: date, end_date: date) -> list[DailyMetric]`**:
       - SELECT DailyMetric WHERE user_id AND date BETWEEN start_date AND end_date, ORDER BY date ASC.
       - Return list.

  <action>
    Create `backend/app/services/garmin_sync_service.py` — the orchestrator that coordinates activity and daily metrics sync for a single user.

    **Imports:** GarminProvider, GarminAuthError from garmin_client; GarminCredential from models; map_garmin_activity, map_daily_metrics from garmin_mapper; create_activity from activity_service; upsert_daily_metric from daily_metric_service; AthleteProfile, Activity from models; AsyncSession; select; logging; date, datetime, timedelta, timezone from datetime; asyncio.

    **Constants:**
    - `INITIAL_BACKFILL_DAYS = 90` — how far back to sync on first connection
    - `DAILY_METRICS_BACKFILL_DAYS = 30` — how far back to sync daily metrics on first connection
    - `SYNC_BUFFER_HOURS = 2` — overlap buffer for incremental sync (handles Garmin upload delay)
    - `INTER_REQUEST_DELAY = 0.3` — seconds between API calls to avoid rate limiting

    **`async def create_garmin_client_for_user(credential: GarminCredential) -> GarminConnectClient`**:
    - Import GarminConnectClient from garmin_client
    - Instantiate with `credential.encrypted_email`, `credential.encrypted_password`, `credential.token_store_path`
    - Call `await client.authenticate()`
    - Return the client
    - On GarminAuthError: update credential.sync_status = "auth_error", credential.sync_enabled = False, re-raise

    **`async def sync_activities(db: AsyncSession, user_id: int, client: GarminProvider, start_date: date, end_date: date) -> int`**:
    - Fetch activities from client: `await client.get_activities(start_date, end_date)`
    - For each raw activity:
      - Call `map_garmin_activity(raw)` — skip if returns None (unsupported sport)
      - Check for existing activity with same external_id: `SELECT Activity WHERE user_id == user_id AND external_id == mapped.external_id`. If exists, skip (idempotent).
      - Load athlete profile: `SELECT AthleteProfile WHERE user_id == user_id` (cache once per sync run, not per activity)
      - Call `create_activity(db, user_id, mapped, profile)` — this auto-calculates TSS
      - Count synced activities
    - Add `await asyncio.sleep(INTER_REQUEST_DELAY)` between batches if doing chunked sync (not between individual activities from the list response — the list endpoint returns all at once)
    - Return count of newly synced activities
    - Log each skipped activity (unsupported sport or duplicate) at DEBUG level

    **`async def sync_daily_metrics(db: AsyncSession, user_id: int, client: GarminProvider, start_date: date, end_date: date) -> int`**:
    - Iterate day by day from start_date to end_date (inclusive)
    - For each day:
      - Fetch all biometric data with defensive error handling (each call in try/except, log and continue on failure):
        - `sleep = await client.get_sleep(day)` 
        - `hrv = await client.get_hrv(day)` 
        - `body_battery = await client.get_body_battery(day, day)`
        - `heart_rates = await client.get_heart_rates(day)`
        - `stress = await client.get_stress(day)`
        - `summary = await client.get_user_summary(day)`
      - Call `map_daily_metrics(sleep, hrv, body_battery, heart_rates, stress, summary)`
      - Call `upsert_daily_metric(db, user_id, day, mapped_data)`
      - Add `await asyncio.sleep(INTER_REQUEST_DELAY)` between days to rate-limit
    - Commit after all days: `await db.commit()`
    - Return count of days with data inserted

    **`async def sync_user_garmin(db: AsyncSession, credential: GarminCredential) -> dict`**:
    - The main entry point for syncing a single user.
    - Create client via `create_garmin_client_for_user(credential)`
    - Determine date range:
      - If `credential.last_sync_at` is None (first sync): start_date = today - INITIAL_BACKFILL_DAYS
      - Else: start_date = credential.last_sync_at - timedelta(hours=SYNC_BUFFER_HOURS)
      - end_date = today
    - For initial sync (last_sync_at is None), fetch activities in 30-day chunks to avoid hitting undocumented pagination limits. Loop from start_date to end_date in 30-day windows.
    - Call `sync_activities(db, credential.user_id, client, start_date, end_date)` (or chunked)
    - Call `sync_daily_metrics(db, credential.user_id, client, metrics_start, end_date)` where metrics_start = max(start_date, today - DAILY_METRICS_BACKFILL_DAYS) for initial sync, or start_date.date() for incremental
    - Update credential: `credential.last_sync_at = datetime.now(timezone.utc)`, `credential.sync_status = "ok"`
    - `await db.commit()`
    - Return `{"activities_synced": N, "metrics_days": M}`
    - On GarminAuthError: set credential.sync_status = "auth_error", credential.sync_enabled = False, commit, re-raise
    - On any other exception: set credential.sync_status = "error", commit, log error, re-raise
  </action>
