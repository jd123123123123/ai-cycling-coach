### `frontend/src/utils/delta.ts`

```ts
export type DeltaTone = 'muted' | 'forest-2' | 'forest' | 'amber' | 'alert'

// Polarized-accent thresholds (§2.4.3):
// |Δ| < 3 → muted | 3-10 good → forest-2 | >10 good → forest | 3-10 bad → amber | >10 bad → alert
toneFromPct(pctChange: number | null | undefined, direction: 'good' | 'bad'): DeltaTone

// 5-case switch returning CSS var() literal strings
tokenForTone(tone: DeltaTone): string  // e.g. 'var(--color-forest-2)'
```

## Decisions Made

- Sport-accent hex values match existing inline constants verbatim — promotion preserves current render, no visual change
- `formatHours` uses Whoop style (always `Xh` suffix) diverging from `WeekStrip.formatHours` (shows `min` for <1h). New function is canonical; WeekStrip will be migrated in Plan 02
- `toneFromPct` uses 'good'|'bad' direction parameter (vs KpiStripCompact's `higherIsBetter: boolean`) — string literal is more readable at call sites; KpiStripCompact migrates in Plan 03
- `RevealCascade` returns `React.ReactElement` not `JSX.Element` — avoids JSX namespace lookup issues without explicit @types/react JSX import in tsconfig.app.json
- No consumers exist yet — Plans 02-05 wire them up; this plan is purely additive
