    - The numeric portion uses `.num-mono` and color-tones via `tokenForTone(toneFromPct(deltaPct, 'good'))` from `utils/delta.ts` (existing helper). Direction interpretation: positive CTL delta = "good" (fitness rising) for the polarized-tone helper.
    - Optional `className` prop passthrough.
    - NO icons. NO motion library (this is a primitive in the honesty layer; static is correct).

    SIGNATURE:
