## Decisions Made

- **String not Enum for target_event_type:** Matches the `primary_sport` column convention. Avoids a future migration when/if we add 'tour' or 'sportive' event types.
- **goals JSONB preserved:** Legacy `goals.target_event_date` still readable by any code not yet migrated. Consolidation is a future cleanup, not a hard requirement for Plan 02.
- **No new API endpoints:** The existing PUT `/athletes/me` PATCH path with `model_dump(exclude_unset=True)` + `setattr` loop picks up the new fields automatically — zero API surface change.
- **Maintenance mode with date=null:** Valid state. Generator falls back to polarized 80/20 base when type='maintenance' OR date is null OR event is >90 days away.
- **Migration apply deferred:** Docker daemon is down per STATE.md. DO NOT run `alembic upgrade head` until Docker is restarted. Migration is correct and chains cleanly.
