## Decisions Made

- **Binary ConfidenceLevel ('high'|'low')** not a 0..1 score — the UI only ever needs to switch between "show the number" and "show the placeholder"; no third state in v1
- **Optional preconditions record** lets polarized (n_days only) and CTL trend (n_days + has_ftp) share one function signature without overloading
- **useState initializer for prefers-reduced-motion** (not useEffect) — ensures the correct shimmer/no-shimmer state is applied on first paint, avoiding flicker
- **Test file as PENDING pending** per [06.1-01] convention — threshold documentation lives in comments even before vitest is installed; void smoke makes them load-bearing at compile time
