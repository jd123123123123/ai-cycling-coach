    2. Create `backend/app/api/garmin.py`:

       **Router:** `router = APIRouter(prefix="/garmin", tags=["garmin"])`

       **POST /garmin/connect** — Connect Garmin account:
       - Depends on `get_current_active_user` and `get_db_for_user`
       - Accepts `GarminConnectRequest` body
       - Check if user already has a GarminCredential. If yes, return 409 Conflict ("Garmin account already connected. Disconnect first.")
       - Create GarminCredential with encrypted email/password, sync_enabled=True, sync_status="syncing"
       - `db.add(credential)`, `await db.commit()`
       - Set token_store_path to a user-specific path: `f"/data/garmin_tokens/{user.id}/"`. Create the directory with `os.makedirs(path, exist_ok=True)`. Update credential with the path, commit.
       - Attempt initial sync: call `sync_user_garmin(db, credential)` in a try/except
       - On success: return 201 with `GarminSyncResponse(activities_synced=N, metrics_days=M, message="Garmin connected and initial sync complete")`
       - On GarminAuthError: delete the credential (bad creds), commit, return 401 with detail "Garmin authentication failed. Check your email and password."
       - On other exception: set sync_status="error", commit, return 500 with detail "Initial sync failed but Garmin account is connected. Sync will retry automatically."

       **DELETE /garmin/disconnect** — Disconnect Garmin:
       - Depends on `get_current_active_user` and `get_db_for_user`
       - SELECT GarminCredential WHERE user_id. If not found, return 404.
       - Delete the credential. Commit.
       - Optionally clean up token_store_path directory (try/except, don't fail on cleanup error).
       - Return `GarminDisconnectResponse(message="Garmin account disconnected")`

       **GET /garmin/status** — Connection status:
       - Depends on `get_current_active_user` and `get_db_for_user`
       - SELECT GarminCredential WHERE user_id.
       - If not found: return `GarminStatusResponse(connected=False)`
       - If found: return `GarminStatusResponse(connected=True, sync_enabled=cred.sync_enabled, last_sync_at=cred.last_sync_at, sync_status=cred.sync_status)`

       **POST /garmin/sync** — Manual sync trigger:
       - Depends on `get_current_active_user` and `get_db_for_user`
       - SELECT GarminCredential WHERE user_id. If not found, return 404 ("No Garmin account connected").
       - If sync_status == "syncing", return 409 ("Sync already in progress").
       - Set sync_status = "syncing", commit.
       - Call `sync_user_garmin(db, credential)`
       - Return `GarminSyncResponse(activities_synced=N, metrics_days=M, message="Sync complete")`
       - On GarminAuthError: return 401 ("Garmin authentication failed. Please reconnect.")
       - On other exception: return 500

    1. Create `backend/app/scheduler.py`:

       ```python
       import logging
       from apscheduler.schedulers.asyncio import AsyncIOScheduler
       from sqlalchemy import select
       from app.database import async_session_maker
       from app.models.garmin_credential import GarminCredential
       from app.services.garmin_sync_service import sync_user_garmin

       logger = logging.getLogger(__name__)

       scheduler = AsyncIOScheduler(timezone="UTC")

       async def run_all_user_syncs():
           """Fetch all users with sync_enabled=True and run incremental sync for each."""
           logger.info("Starting scheduled Garmin sync for all users")
           synced = 0
           failed = 0
           async with async_session_maker() as db:
               result = await db.execute(
                   select(GarminCredential).where(
                       GarminCredential.sync_enabled == True
                   )
               )
               credentials = result.scalars().all()
               logger.info("Found %d users with Garmin sync enabled", len(credentials))

               for cred in credentials:
                   try:
                       stats = await sync_user_garmin(db, cred)
                       synced += 1
                       logger.info(
                           "Synced user %d: %d activities, %d metric days",
                           cred.user_id,
                           stats["activities_synced"],
                           stats["metrics_days"],
                       )
                   except Exception as e:
                       failed += 1
                       logger.error("Sync failed for user %d: %s", cred.user_id, e)
                       # Continue with other users — don't let one failure stop all syncs

           logger.info(
               "Scheduled sync complete: %d succeeded, %d failed", synced, failed
           )
       ```

       - `misfire_grace_time=600` (10 minutes) on the job so server restarts don't skip the sync.

    2. Update `backend/app/main.py`:
       - Import `from contextlib import asynccontextmanager`
       - Import `from app.scheduler import scheduler, run_all_user_syncs`
       - Create lifespan context manager:
         ```python
         @asynccontextmanager
         async def lifespan(app: FastAPI):
             # Add the hourly Garmin sync job
             scheduler.add_job(
                 run_all_user_syncs,
                 "interval",
                 hours=1,
                 id="garmin_sync",
                 misfire_grace_time=600,
             )
             scheduler.start()
             logger.info("APScheduler started with hourly Garmin sync")
             yield
             scheduler.shutdown()
             logger.info("APScheduler shut down")
         ```
       - Pass `lifespan=lifespan` to the `FastAPI(...)` constructor.
       - Add `import logging` and `logger = logging.getLogger(__name__)` at module level.

    3. Verify the scheduler does NOT create its own DB sessions that bypass RLS — the `run_all_user_syncs` uses `async_session_maker()` directly which does NOT set the RLS session variable. This is INTENTIONAL for the scheduler: it's a system-level job that processes all users, not a user-initiated request. The sync_user_garmin function should set RLS within its own DB operations if needed. Verify that garmin_sync_service.py queries are user_id-scoped (WHERE user_id = ...) rather than relying on RLS.
