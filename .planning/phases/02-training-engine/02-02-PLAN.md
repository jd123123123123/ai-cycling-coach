  <action>
    Create backend/app/services/activity_service.py:
    - create_activity(db: AsyncSession, user_id: int, data: ActivityCreate, profile: AthleteProfile) -> Activity
      - Auto-calculate TSS based on sport:
        - cycling: If normalized_power provided, use it. Else if average_power provided, use average_power as NP (fallback per research). Call calculate_cycling_tss(duration, NP, profile.ftp_watts). Skip if no FTP on profile.
        - running: Compute speed from distance_meters/duration_seconds. Call calculate_running_tss(duration, speed, profile.running_threshold_pace_ms). Skip if no threshold pace on profile.
        - gym: Call calculate_hr_tss(duration, average_hr, profile.lthr_cycling or profile.lthr_running, profile.resting_heart_rate, profile.max_heart_rate, sex="male"). Skip if missing HR data on profile. Note: sex field not on AthleteProfile — default to "male" for now, add TODO for later.
      - Set tss on the Activity model before insert
      - Insert activity into DB
    - list_activities(db: AsyncSession, user_id: int, sport: str|None, start_date: datetime|None, end_date: datetime|None, limit: int=50) -> list[Activity]
      - Filter by user_id, optional sport, optional date range
      - Order by started_at DESC, limit results
    - get_activity(db: AsyncSession, user_id: int, activity_id: int) -> Activity|None

    Create backend/app/api/activities.py:
    - POST /activities — accepts ActivityCreate body, gets athlete profile from DB, calls service to create with TSS auto-calc. Returns ActivityRead (201).
    - GET /activities — query params: sport (optional), start_date (optional), end_date (optional), limit (default 50). Returns ActivityListResponse.
    - GET /activities/{activity_id} — returns single ActivityRead or 404.

    All endpoints use get_current_active_user + get_db_for_user dependencies for RLS.

    Register the activities router in backend/app/main.py with prefix="/activities" and tag="activities".
