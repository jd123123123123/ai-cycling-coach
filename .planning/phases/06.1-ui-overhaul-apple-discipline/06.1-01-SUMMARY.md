## Decisions Made

1. **Vitest test infra absent**: `vitest` and `@testing-library/react` are not in `devDependencies`. Test files created as well-typed PENDING stubs with all 12 test cases (6 per component) described in comments and commented-out code bodies. Activation instructions included in each file header. Documented rather than installing infra (installing would touch `package.json` + lock file which is Wave 1 scope-neutral but could affect the bundle baseline).

2. **SideSheet focus trap is manual**: Per plan spec ("Do NOT import `focus-trap-react`"). Implemented via `previouslyFocused = document.activeElement` on open, `tabIndex={-1}` + `.focus()` in 16ms `setTimeout` on the `<aside>` ref, and restore on close.

3. **SideSheet border-radius uses CSS clamp**: `clamp(0px, calc((100vw - 767px) * 9999), var(--radius-xl))` eliminates a JS `matchMedia` listener for the desktop-only left-edge radius. Renders `--radius-xl` on viewports ≥768px, 0px below.

4. **BentoGrid mobile reflow via injected style**: A module-level `document.createElement('style')` injection with `data-bento-cell` selector handles the `<640px` single-column reflow. This keeps `BentoGrid` self-contained without coupling to Tailwind breakpoint utilities.

5. **Pre-existing TypeScript errors in untracked files**: 17 pre-existing TS errors in `DailyInsight.tsx`, `WeeklySportMetrics.tsx`, `PolarizedDistribution.tsx`, `PrescribedWorkoutCard.tsx`, `ReadinessContributors.tsx`, `focusBadge.ts` (all untracked before this wave). These are not regressions from Wave 1 — `vite build` succeeds; `tsc --noEmit` errors exist only in those pre-existing untracked files. Zero errors in any file touched or created by this wave.
