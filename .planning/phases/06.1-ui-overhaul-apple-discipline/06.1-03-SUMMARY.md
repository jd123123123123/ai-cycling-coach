# Phase 6.1 Plan 03: Polish and Power Wave 3 Summary

**One-liner:** Cmd+K command palette (cmdk), ContributorsSheet unified drawer (chatToolUseLog live-subscription, 240ms session-reset), TransparencyDrawer/WhyAmITired retired, AI gradient on CoachChat streaming input, SyncStatusPill masthead freshness, Apple chart polish (PMC/Polarized/Intensity gradients + draw-on animation).

## What Shipped

### Task 1 (prior executor, commit bccae39)
- `CommandPalette.tsx` (~165 LOC): cmdk-based Cmd+K palette with Navigate + Ask coach sections, language-aware, editorial amber/forest/paper styling (no stock cmdk theme). Section prefix "→ " on coach items to prevent label collisions with "A" (Activities wins on "A").
- `CommandPalette.test.tsx`: pending test stub (test infra absent — vitest + @testing-library/react not installed). Stubs documented with exact assertions to activate when infra is added.
- `DashboardShell.tsx`: global Cmd+K/Ctrl+K keybinding via `useEffect`, `paletteOpen` + `coachDraft` state, `<CommandPalette />` portal, `initialDraft` passed into `<CoachChat />`.
- `CoachChat.tsx`: `initialDraft?: string` prop + seed-effect with `lastSeededDraftRef` to prevent re-seeding on re-render.

### Task 2 (commit b4ffb08)
- `ContributorsSheet.tsx` (419 LOC): unified Why-this? drawer with three SegmentedTabs sections:
  - **Contributors** — `<BiometricsDetail />` (readiness breakdown)
  - **Rationale** — `RationaleSection` hoisting WhyAmITired body content (useWhyTired hook, severity icons, translated cause labels)
  - **Tools Used** — `ToolsUsedSection` with live chatToolUseLog subscription
- **240ms session-reset delay location:** `ContributorsSheet.tsx` line ~354, useEffect block:
  ```
  const timer = setTimeout(resetSession, 240)
  ```
  The `resetSession` function sets `currentSection` back to `initialSection` and calls `unsubRef.current()` if still subscribed.
- **chatToolUseLog live-subscription:** `subscribeToolUseLog` called on open → updates `toolUseLog` state in real-time → unsubscribed on close (before the 240ms reset, cleanup function of the open-effect fires immediately on close).
- `ReadinessHero.tsx`: Wave 2 temporary `SideSheet + BiometricsDetail` wiring replaced with `<ContributorsSheet open={contributorsOpen} onClose={() => setContributorsOpen(false)} initialSection="contributors" />`.
- `CoachBrief.tsx`: `WhyAmITired` replaced by `ContributorsSheet(initialSection="rationale")`; `TransparencyDrawer` replaced by `ContributorsSheet(initialSection="tools")`.
- **TransparencyDrawer disposition (dashboard path):** Deleted. No remaining consumers.
- **WhyAmITired disposition:** Deleted. No remaining consumers.
- **`coach/TransparencyDrawer.tsx` shim disposition:** Deleted. Grep confirmed zero consumers: `grep -rn "from.*coach/TransparencyDrawer" frontend/src` returned zero matches.
- `SyncStatusPill.tsx` (85 LOC): reads `['garmin','status']` query key via `useGarminStatus()`. Freshness bands: <30 min → forest/green; 30 min–24 h → amber-soft/ink; >24 h or error → alert/red. Language-aware copy. Click navigates to `/settings`. Hidden on `<640px` (`hidden sm:inline-flex`).
- `DashboardShell.tsx`: `SyncStatusPill` added between `SyncButton` and `LanguageToggle` (additive only; Task 1's Cmd+K + paletteOpen + CommandPalette + initialDraft all preserved).
- `CoachChat.tsx` input gradient: outer `<div className={isStreaming ? 'ai-gradient ai-gradient-rim rounded-[16px] p-[2px]' : ''}>` wraps the input container; inner container drops its border when streaming (`border: isStreaming ? 'none' : '1px solid var(--color-rule)'`). Gradient is a 2px ring — not a full fill. Reduced-motion short-circuited by Wave 1's `@media (prefers-reduced-motion: reduce)` rule in index.css.

### Task 3 (commit df39755)
- **PMCChart.tsx (uPlot):**
  - Y-axis grid removed (`grid: { show: false }` — was previously `stroke`, `width`, `dash`).
  - CTL + ATL gradient fills via `createLinearGradient` in the `series[].fill` factory functions (80%→0% opacity for CTL; 50%→0% for ATL). TSB has no fill.
  - Draw-on animation: `hooks.ready` fades canvas from `opacity: 0` to `1` over 750ms `cubic-bezier(0.65, 0, 0.35, 1)`. Skipped when `prefersReducedMotion()` is true.
- **PolarizedDistribution.tsx:**
  - Bar tiles use CSS `linear-gradient(to bottom, accent 0%, accent99 100%)` (variable named `linearGradient` for grep-visibility). Replaces flat `backgroundColor: accent`.
- **IntensityDistribution.tsx (Recharts PieChart):**
  - `isAnimationActive={!prefersReducedMotion()}`, `animationBegin={0}`, `animationDuration={750}`, `animationEasing="ease"`.
  - Per-slice `<radialGradient>` defs in `<defs>` block; each `<Cell>` uses `fill={\`url(#zone-grad-${entry.zone})\`}`.
- **dashboard.ts ActivityRead:** Added `max_hr: number | null` and `date?: string | null` fields (both exist in backend schema; their absence was causing TS errors in new Wave-2 components).
