## Decisions Made

1. **StickyReadinessBar reads React Query hooks directly** — same `useDailyMetrics` + `useCoachBrief` calls as ReadinessHero; React Query deduplicates. No new API calls, no prop drilling.

2. **WeekStrip mini dot click navigates to `?tab=plan`** — simpler than SideSheet for completed-activity detail (which would require a second query by date). TODO for future polish plan.

3. **TrendsTab PMCChart uses `maxHeight: 320px` wrapper** — non-invasive approach; no changes inside PMCChart itself (Wave 3 handles chart polish).

4. **DashboardShell slot API changed** — `hero/kpiStrip/pmc/collapsedSections` slots removed (they were 04-01 multi-slot props). New API: `children + stickyBar + tabs`. Cleaner composition model for multi-page shell usage.

5. **ActivityDetail minimal view** — `ActivityRead` type has only `id, started_at, sport, duration_seconds, distance_meters, tss, average_hr, normalized_power, title, source`; no `average_power`, `average_cadence`, or `indoor` fields. Detail view uses available fields only.

6. **ReadinessHero `data-testid="readiness-hero"` is permanent** — used by StickyReadinessBar's IntersectionObserver and should survive all future edits to ReadinessHero including Wave 3's ContributorsSheet refactor.

- **Found during:** Task 2 (RecentActivities SideSheet wiring)
- **Issue:** `ActivityRead.id` is typed as `number` in the API types. Initial implementation used `string | null` state type, which would cause type errors.
- **Fix:** Changed `selectedId` state to `number | null` and `onClick` callback to `(id: number) => void`.
- **Files modified:** `frontend/src/components/dashboard/RecentActivities.tsx`
- **Committed in:** `f133d0c` (Task 2 commit)

**3. [Rule 1 - Bug] ActivityDetail used fields not in ActivityRead type**
- **Found during:** Task 2 (ActivityDetail component writing)
- **Issue:** Initial detail view used `average_power`, `average_cadence`, `indoor` — fields not in `ActivityRead`. TypeScript would error.
- **Fix:** Rewrote rows to use only actual `ActivityRead` fields: `duration_seconds`, `distance_meters`, `tss`, `average_hr`, `normalized_power`, `source`.
- **Files modified:** `frontend/src/components/dashboard/RecentActivities.tsx`
- **Committed in:** `f133d0c` (Task 2 commit)

**4. [Rule 1 - Bug] Duplicate React import in ReadinessHero**
