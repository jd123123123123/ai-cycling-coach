Design pass — “Session Report”. A new per-activity surface that rates every ride & run against its prescription, then says what it means and how it shifts your next session. Built on the app’s own tokens (--color-paper / --color-forest / Fraunces / JetBrains Mono) so it drops straight in. Two examples below: a bike ride that ran hot, and a run where the easy run wasn’t easy. Fonts here approximate Fraunces/Geist; the live build uses the real faces.

Reading the bars. The green band is what was prescribed; the dot is where you actually landed — green on target, amber ran hot, red missed. It’s the one glance that answers “did I do the session right?” before any numbers. Every ride & run gets one, bike or run, today or last month.
