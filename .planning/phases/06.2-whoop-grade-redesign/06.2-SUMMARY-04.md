## Decisions Made

- **ProtectedRoute disposition:** Pure-logical wrapper — returns `<Navigate />` or `children`. No visible chrome exists. Classified as "no migration needed" per plan spec. Removed from `files_modified` conceptually, but file was audited and any literals cleaned.
- **Gradient migration strategy:** `rgba(48, 209, 88, 0.10)` → `color-mix(in srgb, var(--color-forest-2) 18%, transparent)`. This removes the hard-coded green and ties the gradient to the theme token, so a future dark/light theme switch would auto-update. Matches ReadinessHero's existing ready-tier pattern (established Phase 6.1).
- **3-dot ordering:** Based on actual App.tsx routing: Login/Register = Account (step 1), GarminConnectPage = Garmin (step 2), ConsentPage/ProfileSetupPage = Goals area (step 3). Documented here for future devs.
