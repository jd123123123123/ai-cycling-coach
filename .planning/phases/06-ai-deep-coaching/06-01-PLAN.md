<objective>
Ship the backend for **COACH-04 analytical Q&A**: extend `/coach/chat` with Claude tool-use so the LLM can answer arbitrary analytical questions ("why am I tired?", "analyze my last 4 weeks", "how's my FTP trending?") by pulling real user data via a closed tool registry.

Purpose: current `/coach/why` is narrow (fatigue only). COACH-04 demands open-ended analytical conversation grounded in the athlete's data — not a canned synthesizer. Tool-use is the mechanism: LLM reasons, requests data, LLM reasons again, produces final narrative.

Output: A tool registry with 5 read-only tools, an extended `/coach/chat` endpoint that runs a tool-use loop, aggregation functions that serve the tools, and a rule-based fallback for the two most common patterns ("why am I tired?", "last N weeks") so chat remains useful without an API key.

**Explicitly not in scope:** workout modification (→ 06-02), chat UI changes (→ 06-03), conversation persistence (stateless; frontend passes last-N turns in 06-04 if scoped).
</objective>

```python
async def run_tool_use_loop(
    messages: list[dict],
    user_id: UUID,
    db: AsyncSession,
    language: Literal["simple", "technical"] = "simple",
    max_iterations: int = 5,
) -> str:
    """
    Tool-use loop. Runs Claude with TOOL_SCHEMAS; handles tool_use blocks
    synchronously; returns final text (streamed by caller).
    Falls back to deterministic synthesizer if settings.anthropic_api_key is None.
    """
    if not settings.anthropic_api_key:
        return await _fallback_analytical_answer(messages, user_id, db, language)

    client = _get_anthropic_client()  # lazy
    system = system_prompt_for_language(language, context='chat_analytical')

    for _ in range(max_iterations):
        response = await client.messages.create(
            model=settings.coach_chat_model,  # COACH_CHAT_MODEL=claude-sonnet-4-6 (cost/latency); Opus reserved for brief generation
            max_tokens=2048,
            system=[{"type": "text", "text": system,
                     "cache_control": {"type": "ephemeral"}}],
            tools=TOOL_SCHEMAS,
            messages=messages,
        )
        if response.stop_reason != "tool_use":
            # Concatenate all text blocks; ED-filter applied by caller
            return "".join(b.text for b in response.content if b.type == "text")

        # Dispatch all tool_use blocks
        tool_results = []
        for block in response.content:
            if block.type != "tool_use":
                continue
            try:
                result = await dispatch_tool(block.name, block.input, user_id, db)
                tool_results.append({"type": "tool_result", "tool_use_id": block.id,
                                     "content": json.dumps(result, default=str)})
            except Exception as e:
                tool_results.append({"type": "tool_result", "tool_use_id": block.id,
                                     "content": f"Error: {e}", "is_error": True})

        messages.append({"role": "assistant", "content": response.content})
        messages.append({"role": "user", "content": tool_results})

    return "Analysis exceeded tool-use budget; returning partial result."
```
