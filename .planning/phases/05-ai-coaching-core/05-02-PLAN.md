<objective>
Replace the "AI brief — Phase 5" placeholder in `ReadinessHero` with a real, causal, transparent coach UI. Every recommendation shows its evidence. Chat drawer lets the athlete interrogate their own data. A transparency toggle reveals the raw snapshot + system prompt (Altini's critique — no black boxes).

Visual language stays paper-themed (cream `#f3ecdc`, Fraunces display, Geist body, JetBrains Mono for data) — matches the editorial dashboard shipped in 04-polish.
</objective>

<context>
**Existing components to integrate with:**
- `ReadinessHero.tsx` has a `<CoachNote>` placeholder — replace it with `<CoachBrief>`
- `DashboardShell.tsx` has nav bar — add "Ask coach" button opens `<CoachChat>` drawer
- `BiometricsDetail.tsx` — extend with decoupling/EF/durability trend tiles (data from activities)
- Tailwind v4 `@theme inline` tokens in `index.css` already define the paper/accent palette

**Backend contracts (from 05-01):**
- `GET /coach/brief` → `{id, generated_at, verdict, rationale, evidence, options[4], outlook_7d, frameworks_cited, model_used, from_cache}`
- `POST /coach/brief/refresh` → same shape, force-regenerate
- `POST /coach/chat` → SSE stream, body `{messages:[{role,content}]}`
- `GET /coach/why` → `{causes:[{label,severity,evidence}], snapshot}`
- `GET /coach/transparency` → `{snapshot, system_prompt, model_used, generated_at}`

**When backend returns 503** (no API key): show "AI offline — showing rule-based brief" chip; chat drawer disabled with "Set ANTHROPIC_API_KEY" tooltip.
</context>

<task id="1" name="api-and-hooks">
Create `frontend/src/api/coach.ts`:
```typescript
export interface BriefOption {
  intensity: 'rest' | 'easy' | 'moderate' | 'push'
  title: string
  why: string
  tss_target: number
  blocked?: boolean
  block_reason?: string | null
}

export interface CoachBriefResponse {
  id: number
  generated_at: string
  verdict: string
  rationale: string
  evidence: Record<string, unknown>
  options: BriefOption[]
  outlook_7d: { day_offset: number; suggested_tss: number; note: string }[]
  frameworks_cited: string[]
  model_used: string
  from_cache: boolean
}

export async function fetchCoachBrief(): Promise<CoachBriefResponse>
export async function refreshCoachBrief(): Promise<CoachBriefResponse>
export async function fetchWhyTired(): Promise<WhyTiredResponse>
export async function fetchTransparency(): Promise<TransparencyResponse>
// Streaming chat: async generator yielding text chunks
export async function* streamCoachChat(messages: ChatMessage[]): AsyncGenerator<string>
```

Hooks in `frontend/src/hooks/`:
- `useCoachBrief.ts` — React Query, staleTime 6h, retry 0 on 503
- `useRefreshBrief.ts` — mutation invalidating brief key
- `useCoachChat.ts` — manages message array + streaming state (isStreaming, partialResponse)
- `useWhyTired.ts` — React Query for `/coach/why`, enabled-controlled (only fetch when modal opens)
