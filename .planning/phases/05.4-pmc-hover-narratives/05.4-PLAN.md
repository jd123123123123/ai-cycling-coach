<objective>
When the athlete hovers the fitness/fatigue (PMC) timeline, each datapoint shows a **generated plain-English summary of what happened that day** — not just CTL/ATL/TSB numbers. Language follows the current `simple|technical` toggle.

Example simple-mode narrative: *"Rest day — CTL slipped 0.2. Form fresh."* / *"68 min ride, 72 effort. Fitness +0.8 — solid aerobic stamp."*

Example technical-mode narrative: *"Rest day (TSS 0). CTL decay −0.2; TSB climbed to +9 (fresh window)."* / *"Endurance session (TSS 72, 68 min @ avg 195W). CTL +0.8; ATL +3.5 → TSB dips to −1 tomorrow."*
</objective>

<context>
**Existing:**
- `GET /training-load/pmc` returns per-day `{date, ctl, atl, tsb, daily_tss}` entries (no narrative)
- `frontend/src/components/dashboard/PMCChart.tsx` (375 lines, Recharts-based) renders with a custom tooltip
- `TooltipContentProps<any, any>` typed per the 04-02 decision (recharts v3 contravariance)

**New:**
- `backend/app/services/pmc_narratives.py` — pure rule-based narrator; no LLM. Deterministic, fast, cheap.
- Enrich `PMCEntry` schema with optional `narrative: str | None` field so the existing endpoint grows a field rather than requiring a new one.
- `PMCChart.tsx` tooltip renders the narrative under the existing numbers.

**Activities-by-date lookup:** narratives need per-day activity info (duration, sport, TSS, intensity-per-hour). The PMC service already sums daily_tss. For narratives we also want: longest single activity of the day, sport mix, rough intensity label (easy / moderate / hard / big). Add a new helper `fetch_daily_activity_summaries(db, user_id, since_date, until_date)` that returns `{date: {duration_min, sport_mix, primary_intensity_label, activity_count}}`.

**Language rules (same as 05.2):**
- Simple mode never uses: FTP, TSS, CTL, ATL, TSB, EF, VI, NP, Z1–Z7, RPE, Seiler, Coggan, Banister
- Technical mode uses those terms freely (no parentheticals needed here — tooltip is compact)
</context>

```python
from __future__ import annotations
from dataclasses import dataclass
from datetime import date
from typing import Literal, Iterable

Language = Literal['simple', 'technical']

@dataclass(frozen=True)
class DayActivity:
    duration_min: float
    primary_sport: str | None         # 'cycling' | 'running' | 'gym' | None
    activity_count: int
    intensity_label: Literal['rest', 'easy', 'moderate', 'hard', 'big']
    # Derived from TSS-per-hour: rest (0 TSS), easy (<45 TSS/h), moderate (45–75),
    # hard (75–110), big (>110 OR absolute TSS >= 120)

def classify_intensity(tss: float, duration_min: float) -> Literal['rest', 'easy', 'moderate', 'hard', 'big']:
    ...

def build_pmc_narrative(
    entry: dict,           # {date, ctl, atl, tsb, daily_tss}
    prev_entry: dict | None,  # for CTL/TSB deltas
    activity: DayActivity | None,  # None means no activities that day
    language: Language,
) -> str:
    """Return a 1-2 sentence summary. Max 140 chars so it fits comfortably in a tooltip."""
```

Narrative rules (simple mode):
| Intensity | Template |
|---|---|
| `rest` | "Rest day — fitness {±delta}. Form {fresh|building|tired}." |
| `easy` | "{duration} min easy. Fitness {+delta}." |
| `moderate` | "{duration} min moderate ride. Fitness {+delta}, still building." |
| `hard` | "{duration} min hard session — {effort} effort. Big stimulus today." |
| `big` | "Big day — {duration} min. Fitness {+delta} but fatigue stacked." |

Where:
- delta = ctl change vs prev day (1 decimal, with sign)
- Form mapped from TSB: > +15 "fresh", +5 to +15 "building", -10 to +5 "balanced", -25 to -10 "tired", <-25 "deep"
- "effort" in simple = "solid" / "hard" / "huge" based on intensity label

Technical mode templates:
| Intensity | Template |
|---|---|
| `rest` | "Rest day (TSS 0). CTL {±d}; TSB {tsb:+.1f} ({form_label})." |
| `easy` | "Endurance {d_min}min (TSS {tss:.0f}). CTL {±d}; ATL {±a} → TSB {tsb:+.1f}." |
| `moderate` | "Tempo/SS {d_min}min (TSS {tss:.0f}, ~{tss_per_hour:.0f} TSS/h). CTL {±d}; TSB {tsb:+.1f}." |
| `hard` | "Threshold/VO2 {d_min}min (TSS {tss:.0f}, ~{tss_per_hour:.0f} TSS/h). ATL {±a} spike — absorption window." |
| `big` | "Big TSS day ({tss:.0f}, {d_min}min). CTL {±d}; TSB plummets to {tsb:+.1f}. Recovery priority." |

Multi-activity days (count >= 2) add a prefix: simple "2 sessions — " / technical "(2× activity) ".

Add unit tests at `backend/tests/test_pmc_narratives.py` covering:
