       ```python
       async def get_activity_details(self, garmin_activity_id: str) -> dict | None:
           await self._ensure_auth()
           try:
               return await asyncio.to_thread(
                   self._wrap,
                   self._api._connectapi,
                   f"/activity-service/activity/{garmin_activity_id}",
               )
           except Exception as exc:
               logger.warning(
                   "get_activity_details failed for %s: %s", garmin_activity_id, exc
               )
               return None
       ```

<task type="auto">
  <name>Task 2: Implement map_activity_streams with downsampling, key-discovery logging, and tests</name>
  <files>backend/app/services/garmin_mapper.py, backend/tests/services/test_garmin_mapper.py</files>
  <action>
    Add to `garmin_mapper.py` a pure function with this signature:

    ```python
    def map_activity_streams(
        raw_detail: dict,
        duration_seconds: int | None,
    ) -> dict | None:
    ```

    Behavior (per RESEARCH.md §"Backend: Stream mapper skeleton"):
    - Read `metricDescriptors` and `activityDetailMetrics` from raw_detail. Return None if either missing/empty.
    - Build `idx_to_key: dict[int, str]` from each descriptor's `metricsIndex` + `key`.
    - Define key buckets: HR_KEYS={"directHeartRate","heartRate","heart_rate"}, POWER_KEYS={"directPower","power","watts"}, ALT_KEYS={"enhancedAltitude","altitude","elevation"}, SPEED_KEYS={"enhancedSpeed","speed"}, CADENCE_KEYS={"directBikeCadence","cadence","bikeCadence","runCadence"}.
    - For each bucket, scan idx_to_key; if a matching key found, extract the column from each entry's `metrics` array (defensive: handle missing/short arrays as None).
    - Refuse to return streams when both HR and power are absent, OR len(metrics) < 10. Return None.
    - Downsample uniformly: `stride = max(1, n // 500)`, indices = range(0, n, stride). Build `t = [i * stride for i in range(len(indices))]` (assumes ~1Hz Garmin sampling — RESEARCH.md acknowledges this is plausible-not-verified; document with a code comment).
    - At top of mapper, log discovered keys ONCE per call: `logger.info("garmin streams keys discovered: %s", sorted(idx_to_key.values()))`. This surfaces field-name variation per Pitfall 1.
    - Return shape:
      ```python
      {
        "sampled_at": <iso utc now>,
        "source": "garmin_connectapi",
        "points": <int>,
        "t": [...],
        "hr": [...] or [None]*points,
        "power": [...] or [None]*points,
        "elevation": [...] or [None]*points,
        "speed": [...] or [None]*points,
        "cadence": [...] or [None]*points,
      }
      ```
    - Guard: `if not duration_seconds: stride = 1` is unnecessary because we derive stride from `len(metrics)`; just ensure no division by duration_seconds in this function.

    Add tests in `backend/tests/services/test_garmin_mapper.py`:
    - test_map_activity_streams_returns_none_when_descriptors_missing
    - test_map_activity_streams_returns_none_when_no_hr_or_power
    - test_map_activity_streams_returns_none_when_under_10_samples
    - test_map_activity_streams_downsamples_to_500_points (build a fake 3600-sample input; assert len(result["t"]) <= 500)
    - test_map_activity_streams_extracts_hr_and_power (build minimal valid descriptors+metrics; assert non-null hr/power arrays)
    - test_map_activity_streams_handles_unknown_keys_gracefully (descriptors with only "directHeartRate"; power should be all None)
  </action>

    3. After a NEW activity is inserted (only when sync produced a new row, not when an existing row was updated), inside an `if fetch_streams and mapped.sport in ("cycling", "running") and mapped.external_id:` guard, call:

       ```python
       try:
           raw_detail = await client.get_activity_details(mapped.external_id)
           if raw_detail:
               streams = map_activity_streams(raw_detail, mapped.duration_seconds)
               if streams:
                   stmt = (
                       select(Activity)
                       .where(
                           Activity.user_id == user_id,
                           Activity.external_id == mapped.external_id,
                       )
                   )
                   result = await db.execute(stmt)
                   act = result.scalar_one_or_none()
                   if act is not None:
                       act.sample_streams = streams
                       await db.flush()
       except Exception as exc:
           logger.warning(
               "Stream fetch failed for activity %s (non-fatal): %s",
               mapped.external_id,
               exc,
           )
       ```
