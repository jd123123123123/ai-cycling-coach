  </files>
  <action>
    1. Scaffold React project: `npm create vite@latest frontend -- --template react-ts`
       If the directory already exists from a previous attempt, remove and recreate.

    2. Install dependencies:
       ```bash
       cd frontend
       npm install axios react-router-dom
       npm install -D @types/react-router-dom tailwindcss @tailwindcss/vite
       ```

    3. Configure `vite.config.ts`:
       - Add Tailwind CSS plugin: `import tailwindcss from '@tailwindcss/vite'` and add to plugins array
       - Add proxy for `/api` to `http://localhost:8000` (avoids CORS issues in development)
       - Set server port to 5173

    4. Add Tailwind CSS import to `src/index.css`: `@import "tailwindcss";`

    5. Create `frontend/src/types/auth.ts`:
       ```typescript
       export interface User {
         id: number
         email: string
         is_active: boolean
         created_at: string
       }

       export interface TokenResponse {
         access_token: string
         token_type: string
       }

       export interface RegisterRequest {
         email: string
         password: string
       }

       export interface LoginRequest {
         email: string
         password: string
       }
       ```

    6. Create `frontend/src/api/client.ts`:
       - Create axios instance with baseURL `http://localhost:8000` (or from env var VITE_API_URL)
       - Request interceptor: attach `Authorization: Bearer {accessToken}` header if token exists
       - Response interceptor: on 401, attempt to refresh token via POST /auth/refresh (withCredentials: true for cookies), then retry original request. If refresh also fails, clear auth state.
       - The access token is stored in a module-level variable (NOT localStorage) — set via exported setter function
       - `withCredentials: true` on the instance for cookie handling

    7. Create `frontend/src/api/auth.ts`:
       - `register(data: RegisterRequest): Promise<TokenResponse>` — POST /auth/register
       - `login(email: string, password: string): Promise<TokenResponse>` — POST /auth/login as form data (OAuth2PasswordRequestForm expects username/password form fields)
       - `logout(): Promise<void>` — POST /auth/logout
       - `refreshToken(): Promise<TokenResponse>` — POST /auth/refresh (withCredentials: true)
       - `getMe(): Promise<User>` — GET /auth/me
  </action>
  <verify>
    1. `cd frontend && npm run build` compiles without errors
    2. `cd frontend && npm run dev` starts dev server on port 5173
    3. Browser opens http://localhost:5173 without errors in console
  </verify>
  <done>
    React+Vite project scaffolded with TypeScript, Tailwind CSS, axios API client with auth interceptors, and typed auth API functions.
  </done>
</task>

    2. Create `frontend/src/components/ProtectedRoute.tsx`:
