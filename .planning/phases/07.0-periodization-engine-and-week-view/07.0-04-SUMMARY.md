# Phase 7.0 Plan 04: Endpoint and Hook Summary

GET /weeks/current wiring mesocycle_generator + weekly_rationale into a language-aware 7-day WeekResponse, with a typed frontend useCurrentWeek hook ready for Plan 05 consumption.

## What Was Built

**Backend:**
- `backend/app/schemas/weeks.py` — Pydantic schemas: `WeekResponse`, `DayPlan`, `MesoBlockContext`, `IntervalBlockOut`, `Language`
- `backend/app/api/weeks.py` — RLS-protected endpoint (`GET /weeks/current`) that:
  1. Loads AthleteProfile, guards on missing profile (409) and missing FTP (409)
  2. Calls `generate_mesocycle(db, user_id, plan_start_date=week_start)` — idempotent
  3. Loads 7 `PlannedWorkout` rows from today through today+6
  4. Assembles `DayPlan` entries with deterministic `_per_day_rationale` copy bank (7 sentences × 7 categories × 2 languages)
  5. Gap-fills days with no `PlannedWorkout` as `category='rest'`
  6. Calls `build_weekly_rationale(...)` for the preface paragraph
  7. Returns `WeekResponse` with `week_start`, `week_end`, `language`, `preface`, `meso_block`, `days`
- `backend/app/main.py` — `weeks_router` registered (`/weeks` prefix, `tags=["weeks"]`)
- `backend/app/services/mesocycle_generator.py` — minor: `_next_monday` defaults to `date.today()`

**Tests:**
- `backend/tests/api/test_weeks.py` — 7 smoke tests using `dependency_overrides` + `AsyncMock` service patches (no real Postgres):
  1. Unauthenticated → 401
  2. Full profile → 200, 7 days, preface non-empty, `days[0].is_today=True`
  3. No `?language=` → `response.language=='simple'`
  4. `?language=technical` → `response.language=='technical'`, preface from technical mock
  5. FTP=0 → 409 with "ftp" in detail
  6. No profile → 409 with "profile" in detail
  7. Maintenance mode (`target_event_date=None`) → 200, `meso_block.days_to_event=null`

**Frontend:**
- `frontend/src/api/weeks.ts` — `fetchCurrentWeek(language)` typed client, `WeekResponse`/`DayPlan`/`MesoBlockContext`/`IntervalBlockOut` TypeScript interfaces
- `frontend/src/hooks/useCurrentWeek.ts` — `useCurrentWeek()` React Query hook with `staleTime: 30 * 60 * 1000`, `refetchOnWindowFocus: true`, language-keyed cache, 409/4xx short-circuit retry
