  <name>Task 1: Build StreamChart primitive (uPlot in rAF, ResizeObserver, spanGaps:false)</name>
  <files>frontend/src/components/dashboard/StreamChart.tsx</files>
  <action>
    Create a new component matching the IntradayModal uPlot pattern. Per RESEARCH.md Pitfall 4, uPlot init MUST be wrapped in requestAnimationFrame so the SideSheet slide-in animation completes before clientWidth is read.

    Signature:

    ```typescript
    type StreamChartProps = {
      t: number[]
      values: Array<number | null>
      label: string
      unit: string
      color: string                 // CSS var or hex
      height?: number               // default 180
      referenceLine?: number | null // for power chart, draws horizontal FTP line
    }
    ```

    Behavior:
    1. Use `useRef<HTMLDivElement>(null)`.
    2. In `useEffect`, schedule init via `requestAnimationFrame`. Inside the rAF callback:
       - Bail if `containerRef.current` is null OR `el.clientWidth === 0`.
       - Build uPlot opts (axes, series, legend:false, cursor with x-only crosshair, spanGaps:false on the data series).
       - If `referenceLine` is non-null, add a second series of constant value (`Array(t.length).fill(referenceLine)`) drawn dashed in muted color.
       - Construct `new uPlot(opts, [t, values, ...maybeRefSeries], el)`.
       - Attach a `ResizeObserver` that calls `plot.setSize({ width: el.clientWidth, height })` on resize.
       - Return cleanup that disconnects RO and calls `plot.destroy()`.
    3. Effect cleanup: `cancelAnimationFrame(id)`.
    4. Render `<div ref={containerRef} className="w-full min-w-0" style={{ height }} />` with an eyebrow label + unit above the chart. Use `eyebrow` class + var(--color-muted) per existing dashboard convention.
    5. Respect prefers-reduced-motion: under reduced motion, skip the rAF defer (init synchronously) since there's no animation race in that case.

    Reference precedent: read `frontend/src/components/dashboard/IntradayModal.tsx` for axis styling, grid colors (`--color-rule`), tick formatting (minutes), cursor config. Reuse the same conventions verbatim — no new design.
  </action>
