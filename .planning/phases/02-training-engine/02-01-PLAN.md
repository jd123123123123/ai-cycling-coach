<feature>
  <name>Sports Science Pure Functions</name>
  <files>backend/app/services/training_load.py, backend/tests/test_training_load.py, backend/tests/__init__.py</files>
  <behavior>
    All functions are pure Python (no DB, no FastAPI). Import numpy only for NP calculation.

    **calculate_np(power_series: list[float]) -> float**
    - 30-second rolling average, 4th power, 4th root (Coggan algorithm)
    - Falls back to simple average if len < 30
    - Empty list returns 0.0
    - Cases: [200]*3600 (steady) -> ~200.0; short list [250,260] -> 255.0

    **calculate_cycling_tss(duration_seconds, normalized_power, ftp_watts) -> float**
    - Formula: (duration_s * NP * IF) / (FTP * 3600) * 100, where IF = NP/FTP
    - Cases: (3600, 280, 280) -> 100.0; (3600, 220, 280) -> ~61.2; ftp=0 raises ValueError

    **calculate_running_tss(duration_seconds, average_pace_ms, threshold_pace_ms) -> float**
    - Formula: (duration_s * speed * IF) / (threshold_speed * 3600) * 100, where IF = speed/threshold_speed
    - Pace is in m/s (higher = faster). NOT min/km.
    - Cases: (3600, 3.5, 3.5) -> 100.0; (3600, 3.0, 3.5) -> ~73.5; threshold=0 raises ValueError

    **calculate_hr_tss(duration_seconds, average_hr, lthr, hr_rest, hr_max, sex) -> float**
    - TRIMP-based: (TRIMP_act / TRIMP_ref) * 100
    - HRR = (HR - rest) / (max - rest), clamped to [0,1]
    - k = 1.92 male, 1.67 female
    - Cases: (3600, lthr, lthr, 50, 190, "male") -> 100.0; trimp_ref=0 returns 0.0

    **update_ctl_atl(ctl_yesterday, atl_yesterday, tss_today) -> tuple[float, float]**
    - CTL_new = CTL_old + (TSS - CTL_old) * (1/42)
    - ATL_new = ATL_old + (TSS - ATL_old) * (1/7)
    - Rounded to 1 decimal place
    - Cases: (0, 0, 100) -> (2.4, 14.3); (50, 50, 0) -> (48.8, 42.9); rest days decay

    **calculate_tsb(ctl, atl) -> float**
    - TSB = CTL - ATL, rounded to 1 decimal
    - Cases: (50, 60) -> -10.0; (60, 40) -> 20.0

    **coggan_power_zones(ftp_watts: int) -> dict**
    - 7 zones with min/max boundaries as percentages of FTP
    - Zone 7 max is None (open-ended)
    - Cases: ftp=280 -> zone1 max=154, zone4 min=255, zone4 max=294

    **seiler_3_zones_running(threshold_pace_ms: float) -> dict**
    - 3 zones: Easy (below 77% threshold speed), Moderate (77-100%), Hard (above 100%)
    - Cases: threshold=3.5 m/s -> zone1 max_speed=2.695, zone2 max_speed=3.5

    **compute_pmc_series(daily_tss_entries: list[dict]) -> list[dict]**
    - Takes list of {"date": date, "tss": float} sorted by date, fills gaps with TSS=0
    - Returns list of {"date": date, "ctl": float, "atl": float, "tsb": float} for each day
    - Handles missing days by filling with TSS=0 (CTL/ATL decay on rest days)
    - Starting CTL/ATL = 0 for new athletes
  </behavior>
