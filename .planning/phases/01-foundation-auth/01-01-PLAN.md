  <action>
    1. Create `backend/app/models/user.py`:
       - `User(Base)` model: id (Integer, PK), email (String, unique, not null, indexed), hashed_password (String, not null), is_active (Boolean, default True), created_at (DateTime with timezone, server_default=now), updated_at (DateTime with timezone, onupdate=now)
       - Relationship: `athlete_profile` (one-to-one, back_populates)
       - Relationship: `consent_records` (one-to-many, back_populates)

    2. Create `backend/app/schemas/auth.py`:
       - `RegisterRequest`: email (EmailStr), password (str, min_length=8)
       - `LoginRequest`: email (EmailStr), password (str)
       - `TokenResponse`: access_token (str), token_type (str = "bearer")
       - `UserResponse`: id (int), email (str), is_active (bool), created_at (datetime)

    3. Create `backend/app/services/auth_service.py`:
       - `password_hash = PasswordHash.recommended()` (pwdlib with Argon2)
       - `hash_password(password: str) -> str`
       - `verify_password(password: str, hashed: str) -> bool`
       - `create_access_token(user_id: int) -> str`: PyJWT encode with sub=str(user_id), exp=now+ACCESS_TOKEN_EXPIRE_MINUTES, iat=now. Algorithm HS256.
       - `create_refresh_token(user_id: int) -> str`: PyJWT encode with sub=str(user_id), type="refresh", exp=now+REFRESH_TOKEN_EXPIRE_DAYS, jti=uuid4 (for future revocation). Use JWT_REFRESH_SECRET_KEY (different from access token secret).
       - `decode_access_token(token: str) -> dict`: decode with JWT_SECRET_KEY
       - `decode_refresh_token(token: str) -> dict`: decode with JWT_REFRESH_SECRET_KEY, verify type="refresh"
       - `create_user(db, email, password) -> User`: hash password, insert, commit, refresh, return user
       - `authenticate_user(db, email, password) -> User | None`: query by email, verify password, return user or None

    4. Create `backend/app/dependencies.py`:
       - `oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/auth/login")`
       - `get_current_user(token: Annotated[str, Depends(oauth2_scheme)], db: AsyncSession = Depends(get_db)) -> User`: decode access token, get user by id, raise 401 if invalid/missing
       - `get_current_active_user(current_user: User = Depends(get_current_user)) -> User`: raise 403 if not is_active

    5. Create `backend/app/api/auth.py`:
       - `router = APIRouter(prefix="/auth", tags=["auth"])`
       - `POST /auth/register`: accept RegisterRequest, check email uniqueness (400 if exists), create user, return TokenResponse + set refresh cookie (httpOnly, secure in prod, samesite=lax, max_age=30 days)
       - `POST /auth/login`: accept OAuth2PasswordRequestForm (username=email), authenticate, return TokenResponse + set refresh cookie. Return 401 on invalid credentials.
       - `POST /auth/refresh`: read refresh_token from cookie (Request.cookies), decode, get user, return new TokenResponse + set new refresh cookie. Return 401 if no cookie or invalid.
       - `POST /auth/logout`: clear refresh_token cookie by setting max_age=0. Return {"message": "Logged out"}.
       - `GET /auth/me`: Depends(get_current_active_user), return UserResponse.

    6. Create initial Alembic migration: `cd backend && alembic revision --autogenerate -m "create users table"`
       - Run migration: `alembic upgrade head`

    7. Wire auth router into `main.py`: `app.include_router(auth_router)`
  </action>
  <verify>

    2. Register: `curl -X POST http://localhost:8000/auth/register -H "Content-Type: application/json" -d '{"email":"test@test.com","password":"testpass123"}' -v` returns 201 with access_token and Set-Cookie header
    3. Login: `curl -X POST http://localhost:8000/auth/login -d "username=test@test.com&password=testpass123" -v` returns 200 with access_token and Set-Cookie
    4. Me: `curl http://localhost:8000/auth/me -H "Authorization: Bearer {token}"` returns user object
    5. Refresh: `curl -X POST http://localhost:8000/auth/refresh --cookie "refresh_token={cookie_value}"` returns new access_token
    6. Logout: `curl -X POST http://localhost:8000/auth/logout --cookie "refresh_token={cookie_value}" -v` clears cookie
    7. Invalid login: `curl -X POST http://localhost:8000/auth/login -d "username=test@test.com&password=wrong"` returns 401
  </verify>
