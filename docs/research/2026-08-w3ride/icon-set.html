The vocabulary a coach speaks

Monoline outline glyphs on a 24-unit grid, 1.5 stroke, rounded joins — the same construction as W3:Ride's icomoon set, but drawn for training science instead of move-to-earn. Every icon is fill:none; stroke:currentColor, so it inherits text colour and drops straight into your components. Metrics first — FTP and the rest — then the bike parts the Garage will need.

How the Garage uses these

Each part icon marks a slot on the bike figure (frame · wheels · tires · drivetrain · saddle · bar tape). Buying a part swaps the layer it points to on the composable SVG bike — the icon is the shop label, the layer is what visibly changes. Tire is drawn heavier because it's the part you named first.

Icon set v1 · 35 glyphs · monoline, 24-grid, 1.5 stroke, currentColor. Drop-in as React components or an SVG sprite. Accented tiles show a candidate hero glyph per group. Extensible — say the word for cadence, RHR variants, TID/polarized, event-type, or more drivetrain parts.
